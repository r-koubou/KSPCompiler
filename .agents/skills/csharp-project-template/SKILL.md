## 使い方

プロンプトで以下の情報が指定されることを想定しています。

- プロジェクト名
- プロジェクトの種類
  - コンソールアプリケーション
  - モジュール


## プロジェクトの種類に応じて実行するシェルスクリプト

シェルスクリプトは scripts ディレクトリをカレントディレクトリとして実行する必要があります。

### コンソールアプリケーション

cli.sh を実行する。

```sh
cli.sh ＜csprojのプロジェクト名＞ _out
```

### モジュール

module.sh を実行する。

```sh
module.sh ＜プロジェクト名＞ _out
```


## 出力先

指定がない場合は `/プロジェクトルート/_out/＜プロジェクト名＞` に出力されます。
シェルスクリプトの第二引数で出力先を指定することも可能です。
